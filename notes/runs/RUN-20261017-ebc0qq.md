Control for [[RUN-20261017-dssg3d]]: does a refresh on the lease's *own* grant leave the
owner's login alone, and does `claude auth logout` revoke a grant server-side. Same scripts
(`experiments/EXP-20261016-rq1408/run-refresh/`), outputs `C-run1.json` and `A-run3.json`

Setup: the rotated pair of the lease grant (A1/R1, held in keychain item

| time | action | result |

| 14:04:14 | `run_lease.sh C` (expired A1, refresh token R1) | `ok`, 1.8 s; new pair A3/R3 in keychain item `Claude Code-credentials-9a1c30cc`; C's file deleted |

grant supersedes every older pair of that grant, and logout revokes the grant at the
server, not just locally. The remaining empty item `-0805ccc4` was deleted by hand.

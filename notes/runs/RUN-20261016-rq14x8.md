## Notes
Background sessions and the session registry.

`claude --bg -n exp05bg "Reply with just the word noted."` printed a short id and the commands
`claude agents`, `attach`, `logs`, `stop` (`experiments/EXP-20261016-rq1405/run-bg/`). `claude logs <id>`
returns the raw terminal output of the background session (ANSI included); `claude stop` and
`claude rm` worked. `claude agents` needs a TTY or `--json`. A wrong id passed to `logs` or
`stop` is not an error: the words are treated as a prompt and a new session answers them,
which cost two stray turns here.

`~/.claude/sessions/<pid>.json` is a registry of interactive sessions with `pid`, `sessionId`,
`cwd`, `kind`, `status` (`idle` or `busy`), `name`, `version`, `messagingSocketPath`
(`/tmp/cc-socks/<pid>.sock`) and `peerFeatures`; a `<pid>.<hash>.key` file sits next to each.
Entries outlive their process, so `pid` must be checked.

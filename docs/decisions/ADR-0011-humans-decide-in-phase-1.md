# ADR-0011: Only humans decide in phase 1; policy rules come later

Status: accepted
Date: 2026-10-16

## Context
Policy (question 11, the owner's answer in `../architecture-questions.md`): human in the loop only, or rules such as auto-allowing read-only
tools.

## Decision
Human decisions only in phase 1; rules on PreToolUse in phase 3.

## Consequences
PreToolUse is recorded but not gated yet.
